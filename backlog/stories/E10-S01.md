# E10-S01 アプリ内課金（月額・年額）

- エピック：E10 課金・フリーミアム
- スプリント：S11（課金）
- 優先度：Must　／　規模：M
- 対応機能：F-11
- 依存：E00-S04

## ユーザーストーリー

利用者として、有料版をアプリ内で簡単に購入・解約したい。安心して試せるようにするためだ。

## 受け入れ条件

- [ ] 月額・年額のプランをApp Store / Google Playで購入できる
- [ ] 無料トライアルの終了日の3日前に通知する（このアプリ自身も解約忘れを起こさない）
- [ ] 設定画面から、ストアの解約画面へワンタップで移動できる

## 技術メモ

RevenueCat 等の課金基盤の利用を検討（ADRで決定）。レシート検証はサーバーで行う。

## テストの観点

購入・更新・解約・返金の各状態の反映。
