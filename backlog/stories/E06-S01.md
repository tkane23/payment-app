# E06-S01 プッシュ通知の基盤

- エピック：E06 通知・予定
- スプリント：S6（通知）
- 優先度：Must　／　規模：M
- 対応機能：F-09
- 依存：E00-S04

## ユーザーストーリー

開発者として、種類ごとにオン・オフできる通知の仕組みを作りたい。利用者が必要な通知だけ受け取れるようにするためだ。

## 受け入れ条件

- [ ] 通知の種類ごとに、利用者がオン・オフを切り替えられる
- [ ] 同じ内容の通知を重複して送らない
- [ ] 夜間（22時〜8時）は送らず、翌朝にまとめる

## 技術メモ

Expo Notifications。送信履歴を保存して重複を防ぐ。

## テストの観点

重複防止、夜間の保留。
