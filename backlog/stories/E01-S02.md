# E01-S02 生体認証によるアプリロック

- エピック：E01 認証・アカウント
- スプリント：S1（認証）
- 優先度：Must　／　規模：S
- 対応機能：F-01
- 依存：E01-S01

## ユーザーストーリー

利用者として、スマホを他人に触られても支出を見られないようにしたい。お金の情報を守るためだ。

## 受け入れ条件

- [ ] Face ID / 指紋でアプリのロックを解除できる
- [ ] バックグラウンドから5分以上経って戻るとロックがかかる（時間は設定で変更可能）
- [ ] 生体認証が使えない端末では、端末のパスコードで代替できる

## 技術メモ

expo-local-authentication。アプリ切り替え画面ではスナップショットを隠す。

## テストの観点

ロック時間の境界値、生体認証の失敗時の挙動。
