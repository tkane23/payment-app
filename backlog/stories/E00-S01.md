# E00-S01 モノレポとCIの構築

- エピック：E00 開発基盤
- スプリント：S0（土台づくり）
- 優先度：Must　／　規模：M
- 対応機能：-
- 依存：-

## ユーザーストーリー

開発者（AI）として、アプリとサーバーを1つのリポジトリで扱いたい。一貫した変更とテストを回せるようにするためだ。

## 受け入れ条件

- [ ] pnpm + Turborepo のモノレポに apps/mobile・apps/api・packages/core・packages/shared がある
- [ ] プルリクエストごとに型チェック・Lint・単体テストがCIで自動実行される
- [ ] README に、ローカルで全体を起動する手順が3ステップ以内で書かれている

## 技術メモ

TypeScript strict。CIはGitHub Actions。packages/core に診断ロジック（UIやDBに依存しない純粋関数）を置く。

## テストの観点

CIが失敗するコミットを意図的に作り、マージできないことを確認する。
