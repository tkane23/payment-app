# プロダクト概要

正式な要件は、プロダクトオーナーが管理する「支払い最適化アプリ 要件定義書」（Claude Docs）を正とします。このファイルは開発に必要な要点の抜粋です。食い違いがあれば要件定義書を優先し、プロダクトオーナーに報告してください。

## 何をつくるか

口座・カードをアグリゲーターAPIで連携し、毎月の支払いを自動で診断して「どうすればいくら安くなるか」を提案するスマホアプリ（iOS / Android）。

## 対象

個人（単身・共働き世帯）。支出は気になるが、家計簿を続ける時間はない人。

## 提供価値

1. **払う前に知らせる**：引き落とし前日、トライアル終了、値上げ、年額更新
2. **具体的に最適化する**：重複・未使用・年額化・支払い経路（キャリア・カードの特典）を、金額と根拠つきで提案
3. **最後まで確認する**：解約手順の案内から、明細での完了確認、削減実績の表示まで

## やらないこと

- 解約・乗り換え・値下げ交渉の代行
- 乗り換えの申込み支援と送客（アフィリエイト）
- 家計簿としての予算管理・純資産管理・信用スコア

## 収益モデル

フリーミアムの月額課金（月400〜600円前後を起点に検討中）。無料/有料の線引きは要件定義書6章。代表的な無料機能：診断サマリー、上位3件の提案、引き落とし前日通知、トライアル終了・値上げ通知、請求ミスの検知、特典の使い忘れの指摘、「使ってる？」チェック。
