# 0006 モバイルと通知はExpo

- ステータス：決定
- 日付：2026-09-27
- 関連ストーリー：E00-S02（実装は E00-S04、E06-S01）

## 背景

iOS・Android の両方に1つのコードで対応し、プロダクトオーナーが毎スプリント実機で確認できる必要がある。プッシュ通知（引き落とし前日・トライアル終了・値上げ）も必要。

## 選択肢

| 領域 | 選択肢 |
| --- | --- |
| アプリ | Expo（React Native）+ EAS Build ／ React Native（Expoなし） ／ iOS・Android それぞれのネイティブ |
| 通知 | Expo Notifications ／ Firebase Cloud Messaging と APNs を直接使う |

## 決定

- **アプリ**：Expo（React Native）+ EAS Build。TypeScript で統一でき（0001）、テスト配布（TestFlight / Google Play 内部テスト）まで EAS で自動化できる。
- **通知**：Expo Notifications。iOS・Android の違いを吸収でき、サーバーからの送信も1つの方法で済む。

## 影響

- 通知の本文と端末のプッシュトークンは、Expo・Apple・Google のサーバーを経由する（東京の外に出る）。本文に含める情報の範囲（サービス名や金額を載せるか）は E06-S01 でプロダクトオーナーと決める。
- EAS Build の料金プランは、E00-S04 でビルド回数を見て決める。
- Apple Developer Program・Google Play Console への登録はプロダクトオーナーが行う。
